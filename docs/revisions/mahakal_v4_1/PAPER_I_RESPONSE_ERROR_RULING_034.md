## 3. The 94.7%/98.1% statistics do not measure the detector error budget

n3_design_033.py::field_error uses tensor-grid bilinear interpolation and divides
absolute primitive differences by the maximum reference magnitude on the comparable
subset. These are GLOBAL-MAX-SCALED PRIMITIVE ERRORS, not pointwise relative errors
and not whitened detector-response errors. The displayed 5e-4 threshold numerically
matches a response budget but has not been derived for these different quantities.

For order 2, the 10284 comparable points cover only 61.6843% of fine emitting nodes.
The comparison has no explicit strictly-interior or common-branch filter. Its core
stencil requires finite redshift and radius, but not that every corner is in the
same emitting domain or radial leg. It can include boundary-crossing or outside-
annulus stencils; their effect must be measured separately before attributing the
entire discrepancy to the smooth interior. Verify coordinate-to-array ordering,
actual x/y spacing, convex interpolation weights and stencil support by fixtures
and raw metadata rather than assuming a reshape is correct or incorrect.

The fine map is a denser numerical comparison, not an established continuum truth.
Raw radius and redshift interpolation is not the measured source response. In the
registered test fields, g enters as g^3 and source time enters through declared
sinusoidal phases. Raw coordinate-time error divided by its absolute zero-dependent
magnitude is not a temporal-response accuracy criterion. Restore the inherited
six screen fields and five g^3/time fields at all eight times; the four primitive
channels in the proposed design do not replace that suite. Other primitives can
remain ancillary diagnostics with their own units. Source radius/azimuth accuracy
will also matter for future source-dependent operators, which are not evaluated here.

Correct the interpretation, not the stored percentages: this is a useful diagnosis
of one bilinear representation on a restricted set of finite stencils. It neither
proves an unavoidable sample count nor demonstrates that adaptivity has removed
all boundary cost. Preserve 94.7% and 98.1% under that precise label.

## 4. The numerical question is an integrated response on a fixed acquisition

For one order, fixed support and a full detector pixel area A_d, write

    delta_y_d = integral_Dd delta_F(xi) dOmega,
    W_dd = 1 / (sigma sqrt(A_d)).

Cauchy-Schwarz gives

    ||W delta_y||_2^2 <= sigma^(-2) integral |delta_F|^2 dOmega.

This is an upper bound on a detector difference from a FIELD norm on matching
support, not a lower bound inferred from the fraction of inaccurate sample points.
For multiple independent channels report the stated norm per field/time and, only
where explicitly intended, the joint stacked norm. A high pointwise error fraction
can integrate to zero; a small such fraction can dominate if it occupies a large
or strongly weighted region. The companion fixture uses a smooth oscillatory field
with >99% of samples above 5e-4 but a vanishing difference on the specified detector.
It is a mathematical counterexample, not a favorable claim about the actual maps.

Compute signed detector vector differences and the absolute-weight error bound,
not just the fraction of nodes crossing a raw-field threshold. Restrict comparisons
to identical known support and retain omitted support as a separately measured
coverage gap. Neither cancellation on known support nor a small partial residual
can certify an unbounded missing contribution. Pointwise envelopes remain necessary
where they are used as physical bounds, rather than being manufactured from samples.

The stated 101416 is a heuristic estimate. In the implementation, the 'interior'
term is ceil(max_fraction_above_threshold * transition_parent_count * 4). This is
not a census of unresolved interior leaves. The stress model then multiplies that
term by four and assumes extra crossings/retries for the boundary term. Unless

worst-case upper bound. If enforced as a hard cap, it bounds work but not success.

between projected work and the retired layout, not a measured speedup. Keep the

A literal request for guaranteed coverage must include counted independent
reference calls and validation. Five percent plus an old comparator-panel count
is a planning convention, not an accuracy or new independent-response guarantee.

## 6. Small scalar-bound correction, not a reversal of signed intervals

leaf2.py::assemble_bounds propagates supplied signed intervals correctly in the
inspected path. However, envelope_response_bound reports the half-width of a box
without specifying the reference response, and applies matrix norm ord=1. The
half-width is a radius about the MIDPOINT, not an arbitrary nominal reconstruction.
For [0,2] and nominal 0, the largest error is 2, not 1. For a 1x2 half-width array
[1,1], matrix ord=1 is 1 while the joint Euclidean box radius is sqrt(2).

Keep interval assembly accepted. Make the scalar report explicit: for diagonal
positive W and a supplied nominal yhat, use componentwise radius
max(|lower-yhat|,|upper-yhat|), then report the Euclidean bound for each channel.
A joint stack must have its own declared aggregation. General correlated whitening
requires its own valid bound. The companion utility implements the diagonal case.
This is a zero-query reporting correction, not a reason to replay 033.
