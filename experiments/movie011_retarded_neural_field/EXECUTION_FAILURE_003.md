# Movie011 execution failure 003 — population serialization interrupted

The vectorized `prepare` attempt deterministically generated all 900 training histories, 24 validation pairs, and 64 test pairs and completed their analytic q8/q12 rendering. The local command envelope then terminated the process while `np.savez_compressed` was serializing the population payload. The resulting 30 MB partial file fails `numpy.load` with `File is not a zip file` and is invalidated.

No usable source bank, source-spec file, clean-response record, neural weight, checkpoint, or test endpoint was produced. The repair changes only artifact serialization from compressed NPZ to ordinary NPZ and writes atomically through a temporary file before rename. Source formulas, generated bytes before serialization, RNG streams, physical responses, network, thresholds, and endpoints are unchanged. The deterministic population is regenerated from the frozen seeds; the corrupted partial file is not consumed.
